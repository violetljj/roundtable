# 圆桌讨论室：Claude × Codex

在一个网页里让 Claude 和 Codex 一起讨论问题，你在旁边实时看，随时插话。

## 启动

双击 **`启动讨论室.cmd`**，浏览器会自动打开 http://127.0.0.1:4545 。关掉那个黑色窗口就停止服务。

需要：Claude Code 命令行已登录（`claude auth status` 显示 loggedIn），Codex 已登录。

## 一场讨论怎么进行

1. **独立提案**：两边同时作答，互相看不到对方的内容，避免先说的一方把另一方带偏。
2. **交叉讨论**：轮流回应对方，可以互相 @ 提问；有实质分歧会保留，不强行统一。
3. **总结 + 复核**：最后没发言的一方写总结（共识、分歧、怎么验证、下一步），另一方检查有没有歪曲自己的观点。
4. **定稿（仅在复核提出更正时）**：由当前额度更宽裕的一方把更正合并进总结，只改被指出的地方。复核无异议就不多调用模型。之前结束的讨论可以在复核下方点「合并成定稿」补一份。
5. 结束后还可以继续自由提问。

两边都认为"可以收敛"、或者到达轮数上限，就进入总结。

## 三种讨论模式

| 模式 | 适合 | 特点 |
|---|---|---|
| 做决定 | 在几个方案里选一个 | 说清代价和选择条件，双方都认为充分时提前收敛 |
| 探索想法 | 头脑风暴 | 各自提 2–3 个不同思路、交叉组合；不提前收敛，讨论到设定轮数；总结是"想法清单" |
| 方案审查 | 审你已有的方案 | 按严重程度找问题和反例，也列出站得住的部分 |

## 约束与事实卡

新建时填的"约束与事实卡"会固定附在双方**每一次**发言的开头，与旧对话、记忆冲突时以它为准。
讨论中点顶部的「约束卡 vN」随时修改：版本号 +1，双方下一次发言会同时收到新旧两版，明确旧版本作废。卡片更新没送达双方之前，讨论不会提前收敛。

## 你能做什么

| 操作 | 效果 |
|---|---|
| 直接发消息 | 排在当前发言之后，下一位先回应你 |
| @Claude / @Codex | 只让这一方回答（不占轮次） |
| 勾选「立即纠正」 | Claude 会被打断、按你的话重来；Codex 不打断，你的话直接插进它正在进行的思考 |
| ⏸ 暂停 | 当前发言说完后不再继续 |
| ✋ 打断 | 立即停止当前发言，没说完的内容不会转给对方 |
| ＋1 轮 / 📋 总结并结束 / ■ 停止 | 加轮数 / 叫停并总结 / 立即停止不总结 |
| 顶部的模型标签 | 随时切换两边的模型和推理强度，下一次发言生效 |
| 顶部的「本场 N/M 次」 | 查看本场每一方的发言次数、token 用量、耗时；调整发言上限和轮数 |

你的每条插话下面会显示送达状态：**等待送达 → 已送达 → 已回应**。"已回应"指对方在一次完整发言里收到了它，不代表一定照做。

本场发言达到上限时讨论会暂停（默认 20 次）。总结、复核、定稿和你主动提的问题不受限制。

## 项目、记忆和桌面端

- **按项目分组**：左侧讨论列表按项目文件夹分组，分组上的「＋」可以直接在该项目里新建讨论。
- **项目上下文自动带入**：选了项目后，Claude 会读 `CLAUDE.md` 和它对这个项目的记忆，Codex 会读 `AGENTS.md` 和它的记忆。新建表单里会显示带入了哪些。
- **带入已有对话**：可以选择 Claude 桌面端（Code 标签页）或 Codex 桌面端里已有的一次对话。讨论室用的是它的**副本**：会记得那次对话的内容，桌面端的原对话不受影响。
- **回到桌面端**：讨论室的 Codex 对话会出现在 Codex 桌面端，名字是「圆桌：话题」。如果你在桌面端打开着它，讨论室会自动复制一份接着用，历史完整保留。总结和复核下方有「复制讨论结论」按钮：会把总结和复核里的更正一起复制（以复核为准），可以粘贴到任一桌面端继续推进。

## 安全

讨论期间两边都是**只读**的：
- Claude：只开放 Read / Grep / Glob 三个工具，不加载任何 MCP 工具。
- Codex：只读沙盒、禁止联网、从不请求审批；插件、电脑操控、浏览器、钩子全部关闭。

服务只监听本机 127.0.0.1，并校验来源，其他网站无法调用。

## 额度

左下角显示两边的账号、套餐和额度用量（Claude 的 5 小时 / 7 天窗口，Codex 的周额度和积分）。
Claude 的额度数据在它每次发言后自动更新。

## 数据存放

每场讨论在 `rooms/<编号>/` 下：`state.json`（完整状态，重启后可继续）和 `transcript.md`（可读的完整记录，也可以点「导出」下载）。

## 开发与协作

这个项目由 Claude 和 Codex 共同开发：

- `AGENTS.md` / `CLAUDE.md`：两边的协作规则（内容一致，Codex 读前者，Claude 读后者）
- `docs/DEVLOG.md`：共同的工作日志，谁做了什么、怎么验证的
- `docs/ARCHITECTURE.md`：开发文档（模块、状态机、协议细节、不能破坏的规则、踩过的坑）
- `docs/ROADMAP.md`：决定记录和下一步计划

## 测试

```bash
node --test test/room.test.js   # 模拟测试，不调用真实模型
node smoke-test.js              # 真实冒烟测试：两边各走一遍 启动→发言→打断→恢复（消耗极少额度）
```

Claude 或 Codex 升级后，跑一下冒烟测试就能发现行为变化。
