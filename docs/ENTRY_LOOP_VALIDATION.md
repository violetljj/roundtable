## 实际观察

| 路径 | 观察 |
|---|---|
| 发言旁核查 | 发送定向请求并关联原发言；补发后得到指定对方的完整核查回复 |
| 起草小实验 | 打开未保存表单，保留原发言出处；原发言是散文，需人工填卡 |
| 保存与批准 | 保存后进入待批准并暂停讨论；单独点击批准后进入运行状态 |
| 独立执行 | 一次真实 Codex 执行会话，最长三分钟，禁网隔离副本；报告验证三类固定解析样例 |
| 失败回传 | 来源变化导致 failed；仍可回传，证据正文保留失败状态、错误与冻结 HEAD |
| 回挂与跳转 | 原发言面板显示一个完整核查回复、双方实验重新判断；核查回复与原文双向跳转实际通过，双方重新判断入口均跳到正确发言 |
| 判断与刷新 | 保存“仍不确定”及注明代操作的理由；刷新后判断、核查及实验关联保留 |

代码核对支持“起草和保存不额外调用模型；批准后才启动实验执行”。此次没有采集模型执行器调用计数，不能把状态观察表述为一次新的零调用计数测试。核查和回传后的讨论、总结与复核消耗模型额度；三分钟仅是实验时限，不是额度上限。
